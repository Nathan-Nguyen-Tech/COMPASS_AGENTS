Update the Meta-Builder knowledge base with new discoveries, learnings, and insights.

**Update Type**: $1 (research, experiment, project-analysis, best-practice, etc.)
**Details**: $2

## Knowledge Update Process

1. **Information Validation**
   - Verify accuracy of new information
   - Check sources and references
   - Validate through testing if applicable
   - Confirm relevance and value

2. **Knowledge Integration**
   - Determine where the information fits in existing knowledge base
   - Identify conflicts with current documentation
   - Update relevant documentation files
   - Cross-reference with related information

3. **Documentation Updates**

   **For Feature Discoveries**:
   - Update `docs/CLAUDE_CODE_MASTER_REFERENCE.md`
   - Add examples to relevant project templates
   - Update optimization checklists if applicable

   **For Best Practice Updates**:
   - Update `docs/OPTIMIZATION_CHECKLIST.md`
   - Enhance `docs/PROJECT_AUDIT_TEMPLATE.md`
   - Update agent configurations if needed

   **For Research Findings**:
   - Add to `research/WEEKLY_RESEARCH_LOG.md`
   - Update `knowledge/PATTERNS.md` with new patterns
   - Document in `knowledge/LESSONS_LEARNED.md`

   **For Experimental Results**:
   - Document in `research/EXPERIMENT_JOURNAL.md`
   - Update relevant templates with proven approaches
   - Add to knowledge base if validation successful

4. **Template and Tool Updates**
   - Update project templates with new best practices
   - Enhance agent capabilities based on learnings
   - Improve slash commands with new insights
   - Refine audit and optimization tools

## Update Categories

### Research Updates
- New Claude Code features discovered
- Official documentation changes

- Integration possibilities and MCP servers

### Experimental Findings
- Feature testing results
- Performance optimization discoveries
- Security configuration improvements
- Workflow automation successes

### Project Analysis Insights
- Cross-project patterns identified
- Successful implementation strategies
- Common pitfalls and solutions
- Standardization opportunities

### Best Practice Evolution
- Updated Anthropic recommendations
- Proven configuration patterns
- Security enhancement strategies
- Team collaboration improvements

## Quality Assurance

Before updating knowledge base:
- **Accuracy Check**: Verify information is correct and current
- **Relevance Assessment**: Ensure information provides value
- **Completeness Review**: Include all necessary context and details
- **Cross-Reference**: Link to related information appropriately
- **Version Control**: Maintain history of changes and reasons

## Knowledge Sharing

After updating knowledge base:
- Notify relevant team members of significant updates
- Update project recommendations based on new knowledge
- Refresh audit templates with new criteria
- Consider implications for existing projects

Use this process to ensure the Meta-Builder knowledge base remains current, accurate, and valuable for all Claude Code project work.

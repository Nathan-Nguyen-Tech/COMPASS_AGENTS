Perform a comprehensive audit of the current project using the project-reviewer agent.

**Focus Area**: $ARGUMENTS (if specified, otherwise perform full audit)

## Audit Scope

1. **Project Discovery**
   - Map the current project structure and technology stack
   - Identify existing Claude Code configuration and usage
   - Understand the development workflow and team practices
   - Assess project maturity and complexity

2. **Configuration Analysis**
   - Review all Claude Code settings files
   - Check security permissions and access controls
   - Evaluate hook implementations and automation
   - Assess agent utilization and command library

3. **Security Assessment**
   - Verify protection of sensitive files (.env, secrets, credentials)
   - Check for destructive command restrictions
   - Review network access and external connection controls
   - Validate audit trail and logging configurations

4. **Feature Utilization Review**
   - Identify missing Claude Code capabilities that could benefit the project
   - Assess workflow automation opportunities
   - Review integration possibilities with external tools
   - Evaluate performance optimization potential

5. **Best Practices Compliance**
   - Compare against current Anthropic recommendations
   - Check documentation completeness and accuracy
   - Review team collaboration configurations
   - Assess maintainability and scalability

## Deliverables

Provide a comprehensive report including:

- **Executive Summary**: Key findings and priority recommendations
- **Detailed Analysis**: Technical review of current setup and configurations
- **Security Assessment**: Vulnerabilities and recommended mitigations
- **Optimization Opportunities**: Quick wins and strategic improvements
- **Implementation Roadmap**: Phased approach with timelines and priorities
- **Risk Analysis**: Potential impacts and mitigation strategies

## Recommendation Categories

- **Immediate Actions** (0-1 week): Quick fixes and essential security measures
- **Short-term Improvements** (1-4 weeks): Valuable enhancements with moderate effort
- **Long-term Strategic Changes** (1-3 months): Architectural improvements

Use the project audit template and optimization checklist to ensure comprehensive coverage of all important areas.

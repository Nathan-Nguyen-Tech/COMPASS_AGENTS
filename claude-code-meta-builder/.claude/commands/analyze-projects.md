Perform cross-project analysis to identify patterns, standardization opportunities, and optimization insights.

**Project Paths**: $ARGUMENTS

## Cross-Project Analysis

1. **Project Discovery**
   - Scan each specified project directory
   - Identify project types and technology stacks
   - Document current Claude Code integration levels
   - Map development workflows and practices

2. **Pattern Identification**
   - Compare project structures and organizations
   - Identify common configuration patterns
   - Document repeated workflow automations
   - Find successful implementation patterns

3. **Standardization Opportunities**
   - Identify areas where consistent approaches would benefit
   - Document configuration variations and their rationales
   - Find opportunities for shared agents and commands
   - Assess security pattern consistency

4. **Optimization Analysis**
   - Compare Claude Code feature utilization across projects
   - Identify underutilized capabilities
   - Find workflow inefficiencies that could be automated
   - Document best-practice implementations that could be replicated

## Analysis Deliverables

### Pattern Analysis Report
- **Common Patterns**: Successful configurations and approaches used across projects
- **Anti-Patterns**: Problematic implementations to avoid
- **Variations**: Different approaches to similar problems and their trade-offs
- **Innovation**: Creative solutions worth replicating

### Standardization Recommendations
- **Configuration Standards**: Common settings that should be consistent
- **Shared Resources**: Agents, commands, and hooks that could be reused
- **Documentation Patterns**: Consistent CLAUDE.md structures and content
- **Security Baselines**: Common protection patterns across all projects

### Optimization Opportunities
- **Quick Wins**: Easy improvements that could be applied across multiple projects
- **Strategic Improvements**: Larger changes that would benefit multiple projects
- **Missing Features**: Claude Code capabilities that aren't being utilized
- **Workflow Enhancements**: Automation opportunities across the project portfolio

### Implementation Plan
- **Priority Matrix**: Ranking improvements by impact and effort
- **Rollout Strategy**: Phased approach for implementing changes
- **Resource Requirements**: Time and skill needs for improvements
- **Success Metrics**: How to measure improvement effectiveness

## Cross-Project Intelligence

Document insights for future reference:
- Update knowledge base with discovered patterns
- Enhance templates with proven approaches
- Create shared agent and command libraries
- Document successful integration patterns
- Build standardization guidelines

Use this analysis to improve both existing projects and guide future project creation with proven patterns and optimizations.

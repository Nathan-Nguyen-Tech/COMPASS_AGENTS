## Research Documentation Standards

### Feature Analysis Template
For each discovered feature:
- **Feature Name and Version**: Official designation and release information
- **Functionality Description**: What the feature does and how it works
- **Use Case Examples**: Practical applications and implementation scenarios
- **Configuration Requirements**: Setup steps and prerequisites
- **Limitations and Considerations**: Known issues and best practices
- **Integration Impact**: How it affects existing configurations

### Experiment Documentation
For research experiments:
- **Hypothesis**: What you expected to discover or validate
- **Methodology**: How you conducted the investigation
- **Environment**: Testing setup and configuration details
- **Results**: Specific outcomes and measurements
- **Analysis**: Interpretation of results and implications
- **Recommendations**: Actionable insights for implementation

### Trend Analysis Format
For broader pattern identification:
- **Pattern Description**: What trend or pattern was observed
- **Evidence Sources**: Where the pattern was identified
- **Frequency Assessment**: How common or widespread the pattern is
- **Value Analysis**: Benefits and drawbacks of the pattern
- **Implementation Guidance**: How to apply the pattern effectively
- **Future Predictions**: Where the trend might lead

# Workspace Directory

This directory contains active work areas and temporary files for the Meta Builder system.

## Inventory

- **WEEKLY_RESEARCH_LOG.md** - Weekly research findings and discoveries (Modified: 2025-09-19)
- **RESEARCH_METHODOLOGY.md** - Research approaches and methodologies (Modified: 2025-09-19)
- **Various research files** - Analysis, experiments, and work-in-progress materials

## Purpose

The workspace serves as the active development and analysis area for:

- **Research**: Ongoing research projects and analysis
- **Experiments**: Testing new approaches and patterns
- **Drafts**: Work-in-progress documentation and materials
- **Analysis**: Data analysis and findings
- **Temporary Files**: Short-term working files and outputs

## Structure Guidelines

This directory should contain subdirectories based on work type:
- `/research/` - Research projects and analysis
- `/experiments/` - Testing and prototyping
- `/drafts/` - Work-in-progress content
- `/analysis/` - Data analysis and findings
- `/temp/` - Temporary working files

Note: The exact structure can be customized based on project needs and user preferences.

## Maintenance

When adding or modifying files in this directory, please update this README following the procedure outlined in `/tools/SOPs/update_readmes.md`.

This directory is excluded from version control by default to keep working files private and temporary.

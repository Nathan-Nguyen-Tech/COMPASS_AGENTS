# Context Directory

This directory contains knowledge and reference materials for the B2B Customer Dashboard project.

## Contents

### business-knowledge/
Domain-specific knowledge about the business and data:

- **customer-fields-explained.md** - Complete reference for all spreadsheet fields
- **dashboard-metrics.md** - Definitions of all metrics and charts in the dashboard

## Purpose

The context directory provides:
- Understanding of business domain
- Data schema documentation
- Metric definitions and calculations
- Interpretation guidelines

## Usage

Agents reference these files to:
- Understand data structure
- Calculate metrics correctly
- Provide accurate insights
- Explain business concepts to users

## Maintenance

When updating context:
1. Keep documentation synchronized with actual data schema
2. Update metric definitions if calculation logic changes
3. Add new business knowledge as project evolves
4. Document any domain-specific terminology

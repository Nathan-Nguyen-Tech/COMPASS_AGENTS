# Meta - Claude Code Meta-Builder

Bạn đang gọi agent **claude-code-meta-builder**.

## Context

Agent này giúp bạn:
- 🏗️ Tạo và tối ưu hóa Claude Code projects
- 📋 Xây dựng cấu trúc project chuẩn
- 🔍 Nghiên cứu best practices
- 📚 Tạo documentation templates
- ⚙️ Setup configurations và permissions

## Working Directory

Thay đổi working directory sang project:
```
cd claude-code-meta-builder
```

## Các chức năng chính

Sau khi vào folder, bạn có thể:
- Tạo Claude Code project mới với cấu trúc chuẩn
- Thiết lập agents, commands, và workspace
- Nghiên cứu patterns và best practices
- Tối ưu hóa existing projects

## Instructions

1. Chuyển working directory: `cd claude-code-meta-builder`
2. Hỏi user muốn làm gì:
   - Tạo project mới?
   - Tối ưu hóa project hiện có?
   - Nghiên cứu patterns?
3. Thực hiện workflow tương ứng

Bắt đầu bằng cách hỏi user: "Bạn muốn tạo project mới hay làm việc với project hiện có?"

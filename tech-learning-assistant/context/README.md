# Context Directory

This directory contains your permanent learning knowledge base - materials that persist across learning sessions and inform the AI agents.

## Structure

### 📚 `/research/`
Permanent learning resources organized by technology/topic.

**What to store here**:
- Official documentation summaries
- Best practices guides
- Tutorial collections
- Reference materials
- Foundational concepts

**Example structure**:
```
research/
├── react/
│   ├── hooks-best-practices.md
│   ├── performance-optimization.md
│   └── official-docs-summary.md
├── typescript/
│   ├── type-system-guide.md
│   └── advanced-patterns.md
└── docker/
    ├── dockerfile-best-practices.md
    └── container-orchestration.md
```

### 🎥 `/transcripts/`
Video transcripts from courses, talks, and tutorials.

**What to store here**:
- Complete course transcripts
- Conference talk transcripts
- Important tutorial series
- Expert explanation videos
- Technical deep-dives

**Example structure**:
```
transcripts/
├── react/
│   ├── react-hooks-complete-course.txt
│   └── react-conf-2024-keynote.txt
├── nextjs/
│   ├── nextjs-14-app-router-tutorial.txt
│   └── vercel-server-components-explained.txt
└── docker/
    └── docker-deep-dive-course.txt
```

## When to Add Materials

### Add to Context When:
- ✅ Material is foundational and will be referenced long-term
- ✅ Official documentation or authoritative sources
- ✅ Complete courses you'll reference repeatedly
- ✅ Best practices that don't change frequently
- ✅ Permanent reference materials

### Use Workspace Instead When:
- ⚠️ Temporary analysis or current learning session
- ⚠️ Experimental materials
- ⚠️ Draft study guides (before finalized)
- ⚠️ Personal notes and scratchwork

## Best Practices

1. **Organize by technology**: Keep each tech/framework in its own folder
2. **Use descriptive filenames**: `react-hooks-best-practices.md` not `notes.md`
3. **Include metadata**: Add source URLs and dates in files
4. **Regular cleanup**: Remove outdated materials periodically
5. **Cross-reference**: Link related materials together

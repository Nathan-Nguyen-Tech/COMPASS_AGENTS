## ⚙️ CÔNG THỨC SO SÁNH

### Quy tắc #1: SO SÁNH BẰNG ĐƠN VỊ NHỎ
```
✅ ĐÚNG:
ton_kho_nho = ton_kho_lon × ty_le_quy_doi
can_mua_nho = max(0, can_nho - ton_kho_nho)

Ví dụ: Găng tay Size M
- Cần: 500 cái
- Tồn: 0 hộp × 50 cái/hộp = 0 cái
- Cần mua: 500 - 0 = 500 cái ✅
```

### Quy tắc #2: QUY ĐỔI SANG ĐƠN VỊ LỚN (ROUNDUP)
```
✅ ĐÚNG (cho Phiếu mua hàng):
can_mua_lon = ROUNDUP(can_mua_nho ÷ ty_le_quy_doi)

Ví dụ: Găng tay Size M
- Cần mua: 500 cái
- Tỷ lệ: 50 cái/hộp
- Phiếu mua: ⌈500 ÷ 50⌉ = 10 Hộp ✅
```

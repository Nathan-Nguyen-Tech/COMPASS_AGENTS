# Context - Knowledge Base

Thư mục này chứa tài liệu hướng dẫn, công thức tính toán, và kiến thức về hệ thống mua hàng tự động.

## 📁 Cấu Trúc

### formulas/
Công thức tính toán cho VTTH và Hóa Chất
- `unit-conversion.md` - Quy đổi đơn vị (QUY TẮC VÀNG!)
- `vtth-calculation.md` - Công thức tính VTTH
- `chemical-calculation.md` - Công thức tính Hóa Chất
- `qc-calib-rules.md` - Quy tắc QC/CALIB

### google-sheets/
Hướng dẫn về cấu trúc Google Sheets
- `sheets-structure.md` - Tổng quan các sheets
- `vtth-sheet-guide.md` - Hướng dẫn sheet VTTH
- `chemicals-sheet-guide.md` - Hướng dẫn sheet Hóa Chất
- `template-guide.md` - Hướng dẫn template phiếu mua hàng

### workflows/
Quy trình nghiệp vụ
- `complete-workflow.md` - Quy trình đầy đủ từ đầu đến cuối
- `inventory-comparison.md` - Quy trình so sánh tồn kho
- `troubleshooting.md` - Xử lý lỗi thường gặp
